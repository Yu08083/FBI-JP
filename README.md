# FBI 日本語版

[FBI 2.6.1](https://github.com/Steveice10/FBI)の日本語版です。

- 日本語化: **yu_**
- 原作者: **Steveice10**

[ダウンロード](https://github.com/Yu08083/FBI-JP/releases/latest)

`FBI-JP.cia`をSDカードに置き、FBIからインストールしてください。既存のFBIを置き換えます。
